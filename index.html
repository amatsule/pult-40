ПУЛЬТ-40

Добро пожаловать на пост оперативного дежурного! Вы управляете городской системой оповещения на базе легендарных советских сирен С-40.

1. Выберите район(ы) на карте — не включайте сирену там, где угрозы нет!
2. Выберите тип сигнала: протяжный ревун для угрозы или короткие гудки для проверки.
3. Соберите текст из 3 блоков и нажмите «В ЭФИР».
4. Перехватите ТВ/Радио тумблером при реальной угрозе (при проверке не нужно).
⚠ Будьте бдительны: чините красные вышки («Нет связи») и отклоняйте ложные розыгрыши!

РЕГЛАМЕНТ РАБОТЫ С «ПУЛЬТ-40»

🚨 Реальная угроза (ураган, дым, пожар, потоп, авария):

Выберите ТОЛЬКО указанные в донесении районы → Протяжный ревун → включите тумблер Перехват ТВ/Радио → соберите верный текст из 3 блоков → нажмите «В ЭФИР».

🔔 Плановая проверка сирен:

Выберите указанные районы → Короткие гудки → тумблер Перехват ТВ/Радио оставьте ВЫКЛ → соберите текст про проверку → нажмите «В ЭФИР».

🤡 Ложный вызов (розыгрыш):

Если сообщение явно абсурдное (летающие пончики, говорящие белки, пропавшая котлета) — НЕ включайте сирену! Нажмите кнопку «ОТКЛОНИТЬ (ЛОЖНЫЙ ВЫЗОВ)».

⚡ Поломка на линии («Нет связи»):

Кликните по мигающей красной вышке на карте. Программный сбой чинится мгновенной Перезагрузкой. Обрыв кабеля или удар молнии чинит Рембригада (либо перезагрузка после покупки «Спутниковой связи»).
