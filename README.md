# ПУЛЬТ-40 — Браузерный симулятор системы оповещения

Игра-симулятор оперативного дежурного городской системы оповещения на базе легендарной советской сирены **С-40** (HTML5 + CSS3 + Vanilla JavaScript + Web Audio API).

## Как запустить

1. **Прямой запуск:** просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox).
2. **В Visual Studio Code:** откройте папку проекта в VS Code и запустите `index.html` через расширение **Live Server** (правый клик по `index.html` → *Open with Live Server*).

## Структура проекта

- `index.html` — разметка рабочего стола дежурного, CRT-монитора, пульта сирен, мини-телевизора и модальных окон.
- `css/style.css` — ретро-индустриальный стиль бункера, мигающая красная лампа, тумблер перехвата ТВ и CRT-эффекты.
- `js/data.js` — 6 районов города, 12 вышек, донесения (реальные угрозы, плановые проверки, ложные вызовы), блоки сообщений и улучшения.
- `js/audio.js` — процедурный синтезатор звуков на Web Audio API (советская С-40, американская сирена торнадо, современная цифровая, короткие гудки, тумблер, зуммер, гром и озвучка диктора через SpeechSynthesis).
- `js/map.js` — интерактивная карта города на HTML5 Canvas с мигающими зелёными вышками, красными поломками и акустическими волнами.
- `js/game.js` — игровой цикл смен (5–7 минут), 30-секундный таймер реакции, ремонт вышек, прокачка пульта и сохранение прогресса.
